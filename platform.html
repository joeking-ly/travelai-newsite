Unified platform

One engine. Every surface.

TravelAI runs on a single engine that adapts to every surface, channel, and agent. We meet travelers where they are: web, chat, voice, messaging, partner sites, or Slack. The same core carries the same memory to every touchpoint, so a traveler never starts from zero twice.

This isn't a product suite bolted together. It's one system with four responsibilities: hold memory for the traveler, move it with trust between partners, govern it for the enterprise, and distribute it across a live network. The sections below show how each responsibility runs today.

The platform

Memory, trust, governance, distribution.

01 Memory — Context the traveler owns.

Traveler.md — The open, human-readable memory standard at the center of the platform. A traveler's preferences, history, and intent in one portable file: owned by the traveler, granted to any agent, revoked anytime.

TAM Engine — Traveler Action Models turn that file into pseudonymous preference vectors that sharpen with every interaction. Never PII.

02 Trust — Trust the traveler already extends.

Trusted Brands — We acquire and build brands travelers already know, including Sonder, OwnerDirect, Smartours, Casai, and RentByOwner. That inherited trust transfers to the platform, so an agent acting for a traveler carries a name they recognize.

Trusted Agents — A vetted network of agents, like Tripp our third voice concierge, authorized to act on a traveler's behalf and grounded in their memory. Trust is earned over a lifetime and lost in an instant, so every agent on the network has to prove whose behalf it acts on.

03 Governance — Control the enterprise can defend.

Governed Memory Platform (in development) — The consent, audit, and replay layer that sits over Traveler.md. Every read of traveler memory is granted, logged, and reviewable, so OTAs, TMCs, and enterprise programs can put agents to work and still answer for every decision.

Replay & Audit — Reconstruct any interaction after the fact: who authorized it, on what terms, and what the agent did with it. Every decision is defensible, so compliance and partners can inspect the record instead of trusting a black box.

04 Distribution — The network it all runs on.

Owned Network — 530+ sites reaching 50M+ travelers a year across 200 countries. The starting point, where portable traveler context is created and begins to travel.

Partner Network — Integrations with OTAs, DMOs, and TMCs so a traveler's context follows them across the whole journey, not just our own sites.
